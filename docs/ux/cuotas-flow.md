# Flujo UI: cuotas

## Pasos

1. Login PIN tesorera
2. Listado + buscador
3. Ficha del estudiante (grid 10 meses + historial)
4. Formulario “Registrar pago”
5. Confirmación y grid actualizado

## Principios

- Progressive disclosure: primero buscar, luego detalle
- Progreso visible en 10 casillas de mes
- Ayuda junto al importe: a qué mes se aplica
- Accesibilidad: labels, foco, contraste ≥ 4.5:1, botones ≥ 44px
