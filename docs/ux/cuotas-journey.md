# User journey: registrar un pago

## Persona

Tesorera, goal = anotar el pago en el historial correcto.

## Stages

### 1. Entrada

- Doing: abre PagaTiempo e inicia sesión con PIN
- Thinking: “¿Está el servidor arriba?”
- Feeling: prisa si hay fila de estudiantes
- Opportunity: login corto, mensaje claro si falla la API

### 2. Búsqueda

- Doing: escribe “mar” en el buscador
- Thinking: “Que no me confunda con otro nombre”
- Feeling: concentrada
- Opportunity: resultados filtrados al instante, un alumno por fila

### 3. Historial

- Doing: abre a María, mira 10 meses e historial
- Thinking: “¿Cuánto le falta a octubre?”
- Feeling: necesita certeza
- Opportunity: grid de meses + lista de movimientos

### 4. Acción

- Doing: elige mes (o automático) e importe
- Thinking: “¿Se grabó?”
- Feeling: alivio si hay confirmación
- Opportunity: estado pendiente en el botón, toast/alert de éxito

### 5. Resultado

- Doing: verifica saldo y cierra o busca al siguiente
- Success: total pagado + meses coinciden con lo cobrado
